gemini_script.py

Basic function: an interactive chat script for Google Gemini. It reads your GEMINI_API_KEY environment variable, asks you a question in a loop, sends it to the Gemini API, and prints the response until you type exit or quit.

Basic function: a Tkinter-based YouTube downloader. It gives you a small GUI with a URL field, a folder picker, and a Download button. It uses yt-dlp to download the selected video/audio into the chosen folder and shows success or error popups.

send_email.py

Basic function: an email-sending helper for SMTP Gmail. It builds an HTML email message, sets the subject and recipient, connects to Gmail via SSL, logs in, and sends the message. It looks like it is intended for a daily CVE/briefing email.
